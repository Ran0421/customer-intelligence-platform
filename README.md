# Customer Intelligence & Churn Analytics Platform

An end-to-end analytics and machine learning platform for customer churn analysis, business intelligence, and retention analytics.

## Features
- SQL analytics
- Customer segmentation
- Churn prediction
- Power BI dashboard
- Streamlit deployment
- AI-generated business insights

## Tech Stack
- Python
- SQL
- PostgreSQL
- Power BI
- Streamlit
- XGBoost
